One diagnosis from an AI therapist, delivered in its calm clinical voice — until the last clause flips who is billing whom.

> Diagnosis: main-character syndrome — your inner monologue talks like the hero of the story and bills like the therapist.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (120 characters, one line, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
